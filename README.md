# Sports Campaign Landing Page Concept

Responsive landing page concept for a sports campaign and promotional product
launch.

Live project: https://19reginab91.github.io/Hannah-sport-campaign-landing/

## Overview

This project is a portfolio landing page concept built around a sports jersey
promotion and campaign-style user journey.

The goal was to create a clear and energetic promotional page with product
presentation, giveaway information, timeline content and strong call-to-action
sections.

## Concept

The website presents a campaign for a football jersey promotion connected to the
WM 2026 theme. It is structured as a landing page, guiding visitors from the main
offer to team selection, giveaway details, campaign dates and final action.

This is a concept project created for my frontend and UI design portfolio.
