## 👕 Konzept

Zur WM 2026 wird eine Verkaufs- und Gewinnspielaktion umgesetzt.

- Trikots verschiedener Nationen
- Einstiegspreis: 9,99 €
- Automatische Teilnahme an Gewinnspielen

Aktuell:
- Deutschland-Trikot aktiv
- Weitere Länder folgen (Türkei, Portugal, Brasilien, Spanien)

---

## 🎁 Gewinnspiel

Alle Käufer nehmen automatisch teil:

- 10.06.2026 → Hauptverlosung
- 11.06.2026 → WM-Eröffnungsspecial
- ab 12.06.2026 → tägliche Gewinne
